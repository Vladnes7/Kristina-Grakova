# Студия Граковой Кристины

Одностраничный сайт ногтевой студии на Лесной, 4А.

Статическая страница без сборки: весь HTML, CSS и JS лежат в одном файле
`index.html`. Tailwind подключён через CDN, шрифты — Google Fonts.

```
index.html                    вся страница
Materials/
  hero_photo_cropped.png      фото главного блока
  logo.png                    оригинал логотипа (бренд-ассет)
  studio_info.md              справочник по контенту: цены, отзывы, факты
  Portfolio Photos/           15 фото работ
```

## Посмотреть локально

Двойной клик по `index.html` работает, но надёжнее поднять сервер — иначе
браузер может ругаться на пути к фотографиям:

```bash
npx serve .
```

## Публикация на Vercel

Сборка не нужна, это статический сайт.

1. [vercel.com/new](https://vercel.com/new) → **Import Git Repository** → выбрать
   этот репозиторий.
2. Framework Preset: **Other**. Build Command и Output Directory оставить пустыми.
3. **Deploy**.

Дальше каждый `git push` в ветку `main` разворачивается автоматически.

## Что ещё не сделано

- **Ссылки на Telegram — заглушки.** Во всех кнопках записи стоит `href="#"`.
  Найти по файлу `href="#"` и подставить реальный адрес `https://t.me/...`
  (сейчас таких мест девять: верхняя строка, меню, главный блок, галерея,
  блок записи, контакты и три в футере — кнопка, ссылка и иконка).
- **Фотографии тяжёлые** — около 20 МБ на загрузку страницы. Стоит пережать
  в WebP перед тем, как давать ссылку клиентам.
- Телефона и почты в исходных данных нет — в контактах только адрес, часы
  и Telegram.
